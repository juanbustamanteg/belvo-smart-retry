From lo-fi to MVP

Each screen needs

  • S1 server login, revocable session, expiry
  • S2 runs list and history availability
  • S3 upload, validate, set cooldown
  • S4 run job with atomic commit and Interrupted recovery
  • S5–S6 paginated decisions and per-loan evidence
  • S7 submit, withdraw, approve, return
  • S8 export restricted to Approved

Questions to settle before building

  • Detail as side panel or full page? Board assumes side panel so the queue stays in view.
  • Should Waiting sort by next check date by default?
  • Should Needs attention group by reason, or stay one flat list with a reason filter?

Out of scope in this board

  • Visual identity and polish
  • Payment execution, amounts, scheduling
  • Multi-merchant tenancy, user admin
